# English version (`l=en`; Hebrew is authoritative)

- **Every new string needs both languages:** a key in `strings.js` needs its twin in `strings.en.js` (the parity test fails otherwise). An English string has no Hebrew except the toggle label and a ballot letter.
- **Every Hebrew text field in the data has an `en` twin** (`parties`, `topics`, `meta`, results `splitNote`, scenario sources), and every position has `summaryEn`, plus `quoteTranslationEn` for a quote not in English. `validate.mjs` fails otherwise. Records are localized with `localize()`; party order is always computed from the Hebrew data.
- **Translation flow:** `research/translate-brief.md` (rules and glossary) → `research/translations-en.json` → independent verifier (`research/verify-en-brief.md`: blind back-translation first, then the comparison) → resolve every flag (disputes go to the user) → `node scripts/apply-translations.mjs` (→ `summaryEn`/`quoteTranslationEn` in `research/merged.json`, and `en` in `topics.json`) → export → import (`.claude/rules/data.md`). Before exporting, make sure `research/merged.json` matches `site/data/positions.json` (it fell behind once; see decisions.md), and check the import with `git diff`: only the intended fields may change.
- **Names:** GPO English list → the party's or person's own English → transliteration. A Hebrew party name is transliterated unless it has an established English name. Leaders as they spell themselves. Ballot letters stay Hebrew (`lang="he"`). The official list name is shown verbatim in Hebrew with our translation. Names in the data's Hebrew fields (quote speakers, channels) go through `NAMES` in `strings.en.js`.
- **Quotes** stay in their original language; the English page shows the site's translation under them, marked as such. The required Hebrew poll sentence (polls mode) is shown verbatim before its translation.
- **Language in the URL:** `l=en` in the fragment (never the query); Hebrew is the default and is omitted. A shared English link previews in Hebrew (#21).
- **Smoke** runs every case also with `l=en`: lang/dir, the translation notice, no Hebrew outside `lang="he"`, the same numbers, links keeping `l=en`, the toggle.
